## 一、确认的结论（三次实验一致）

### 1. temperature = 0 **不保证可复现**

| 实验 | T=0 的表现 |
|---|---|
| A：同一句话问 20 次 | **20 种不同回答** |
| C 任务 2：同一句话问 20 次 | **20 种不同回答** |
| C 任务 1：单 token 选词，40 次 | **60% / 25% / 15%**，完全没有收敛 |

一个"单 token 决策"都能散成 60/25/15，说明**服务端的非确定性不小**。

### 2. 噪声会随生成长度被放大

```
任务 1：输出 1 个 token  →  T=0 的集中度只有 60%
任务 2：输出 ~55 个 token →  T=0 的重复率是 0/20
```

哪怕每个 token 只有 1% 概率被翻转，55 个 token 之后整句不变的概率也只有
`0.99^55 ≈ 58%`；而实测的翻转率远高于 1%，所以**长输出必然不重复**。

### 3. 噪声地板不是一个固定数字，它取决于题目难度

| 任务 | 模型有多确定 | 波动 |
|---|---|---|
| 3 位数乘法（30 题） | 极高（答案唯一） | **零波动**，5 遍全 100% |
| 解释数据库索引 | 低（说法千千万） | **20 遍 20 种** |

同一套代码、同一个模型、同一个 temperature，波动天差地别。

> **结论：你必须在"和真实评测集难度相当"的题上测噪声地板。**
> 阶段 3 有了真正的 RAG 评测集（准确率大概 60~80%）之后，
> **要在那套题上重新测一遍。**

### 4. 波动只有在"答案会收敛"的任务上才是不确定性信号

- 乘法题 T=1 下零波动 → 模型确定
- 解释题 T=1 下大幅波动 → 但这**不是**模型不确定事实，
  而是**同一个事实有很多种说法**

> 这决定了阶段 4 的自一致性只能用在哪：
> 数学、分类、抽取（有唯一答案）可以；
> 写文案、开放式生成**不行**——5 个答案里没有"多数"可言。

## 三、我犯的两个实验设计错误（这段最值得看）

| # | 实验 | 错在哪 |
|---|---|---|
| 1 | 30 道 3 位数乘法 | **太简单**，模型 5 遍全对 → 分数恒为 100% → 零区分度 |
| 2 | "从三个词里随机选一个" | **我在 prompt 里写了"随机"**，等于命令模型把概率压平 → T=0 没有第一名可收敛，T=2 没有空间可摊开 → 上下都没有区分度 |

**同一个错误，连着犯两次。**

而且第二次更隐蔽：任务的答案种类少（3 种）、看起来"适合做分布分析"，
但它**在概率形状上被设计成了没有区分度**。

> ### 核心教训
> **"设计一个有区分度的实验"是一项独立技能，比看起来难得多。**
>
> 对照组不是随便挑个任务就行。在跑之前，你必须能回答：
> **"如果我的假设成立，这个实验的读数会怎么变？如果假设不成立，又会怎么变？
>  这两个读数会不会差不多？"**
>
> 如果两个问题的答案都是"差不多"，那这个实验**白跑**。

另外——这两次也正好是 level0 想教的东西本身：
**n 太小测不出差异、题目没有区分度就测不出差异。**
level0 的教训，在 level0 自己的实验上又应验了一遍。

## 四、我的学习总结（自己填，下面是我的）

### 我学到了

1. 什么是 temperature：它是"从模型给出的候选里抽签的随机程度"
2. 什么是 softmax：把任意分数变成概率（每个 ≥ 0，加起来 = 1）
   ```
   logits(原始分数) → 除以 T → softmax → 概率 → 抽签 → 选出一个词
   ```
3. temperature 影响概率分布：T 小 → 拉开，T 大 → 抹平

### 我漏掉的（level0 真正的重点）

上面三条都是**"这东西怎么工作"**（机制）。但 level0 的目的是另外三条：

- [ ] **分数会晃** —— 什么都没改，重跑分数就不一样
- [ ] **题太少 / 题太简单，就测不出差异**（n=30 测不出 4%）
- [ ] **T=0 也不保证可复现** —— 因为服务端有非确定性

> **这个偏向值得记住**：我天然被"机制"吸引，而我列出的六个短板
> （eval、数据、模型行为、实验、监控、回流）**全是"测量"**。
>
> 这意味着后面几个 level，我需要**主动**把注意力放在
> "我怎么知道它变好了"上面，而不是"它是怎么工作的"。
> 机制让我觉得舒服，测量让我觉得枯燥——而枯燥的那部分才是缺口。
