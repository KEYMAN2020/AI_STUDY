# AI_STUDY

AI 系统工程师 · 沙盘学习路线。

从零搭一条**自己能完全理解**的模型链路，把短板
（eval / 数据 / 模型行为 / 实验 / 监控 / 数据回流）
在一条链路上各走一遍。

> 定位：用工程手段治理模型的不确定性。
> 核心问题只有一个：**我怎么知道它是对的？**

---

## 目录

| 路径 | 内容 |
|---|---|
| `学习路线.md` | 总路线：11 个阶段，每阶段带产出物、自检问题、时间估计 |
| `level0/` | **噪声地板** —— temperature 是什么、为什么 T=0 也不可复现、分数会晃多少 |

| `level2/` 起 | 待建（从零 RAG → 第一份 eval → 不确定性 → …） |

## 从哪开始

1. 先读 `学习路线.md` 的**「目录约定」**和**「为什么是这个顺序」**两节
2. 然后按 level 顺序往下走，**不要跳**
   - 每个 level 都以前一个的产出物为前提
   - 阶段 3 和 4 是多数人放弃的地方，但价值最高

| `README.md` | 这一关的计划、步骤、验收标准、自检问题 |

## level1 的内网方案

公司内网调不了外部模型？**不用等回家。**

`level1/mock_server.py` 是一个**本地假 API 服务器**，纯标准库。
你的代码照样真的发 HTTP 请求、真的收状态码、真的解析 JSON，
只不过目标是 `127.0.0.1`，不走外网。

它能模拟：慢响应 / 429 限流 / 500 / 401 / 坏 JSON / 空回答 / 前两次失败。

回家只改一行：

```python
BASE_URL = "http://127.0.0.1:8000"       # 内网：假服务器
BASE_URL = "https://api.deepseek.com"    # 回家：真模型
```

**内网能完成 level1 的 95%**，而且覆盖的是真实 HTTP 路径，不是假装的。
